# Package index

## Navigating a Conversation

One stop shop for building a Shiny app to explore a conversation

- [`ls_plot_static()`](https://jpcompartir.github.io/LandscapeR/reference/ls_plot_static.md)
  : Create a landscape plot without segmenting by groups
- [`ls_plot_density()`](https://jpcompartir.github.io/LandscapeR/reference/ls_plot_density.md)
  : Landscape hexplot coloured by density
- [`ls_plot_group_facet()`](https://jpcompartir.github.io/LandscapeR/reference/ls_plot_group_facet.md)
  : Create static plots for each level of a grouping variable.
- [`ls_plot_group_static()`](https://jpcompartir.github.io/LandscapeR/reference/ls_plot_group_static.md)
  : Create a landscape plot and colour in each level of a grouping
  variable.
- [`ls_plot_variation_matrix()`](https://jpcompartir.github.io/LandscapeR/reference/ls_plot_variation_matrix.md)
  : Compare proportion of x in y
- [`ls_plot_group_vol_time()`](https://jpcompartir.github.io/LandscapeR/reference/ls_plot_group_vol_time.md)
  : Quickly plot faceted volume of groups over time in a LandscapeR
  Shiny App
- [`ls_plot_group_sent()`](https://jpcompartir.github.io/LandscapeR/reference/ls_plot_group_sent.md)
  : Quickly plot group sentiment distributions as a percentage in
  LandscapeR shiny app
- [`ls_wlos()`](https://jpcompartir.github.io/LandscapeR/reference/ls_wlos.md)
  : A LandscapeR version of ParseR's Weighted Log-odds
- [`ls_sentiment_over_time()`](https://jpcompartir.github.io/LandscapeR/reference/ls_sentiment_over_time.md)
  : View a sentiment and volume over time chart

## Utility Functions

Exported functions for use elsewhere

- [`column_type_checker()`](https://jpcompartir.github.io/LandscapeR/reference/column_type_checker.md)
  : Quick function for checking if a column is of the right type using
  data-masking
- [`ls_link_click()`](https://jpcompartir.github.io/LandscapeR/reference/ls_link_click.md)
  : Prepare a URL column to be clickable in Shiny/Data Table
- [`reactive_labels()`](https://jpcompartir.github.io/LandscapeR/reference/reactive_labels.md)
  : Programmatically generate reactive labels from a prefix
- [`ls_create_note_area()`](https://jpcompartir.github.io/LandscapeR/reference/ls_create_note_area.md)
  : Add a re-sizeable text area to take notes in!
