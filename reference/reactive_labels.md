# Programmatically generate reactive labels from a prefix

Programmatically generate reactive labels from a prefix

## Usage

``` r
reactive_labels(prefix, input)
```

## Arguments

- prefix:

  type of plot e.g. 'sentiment'

- input:

  reading from Shiny's server `input` object - the list of all inputs.

## Value

ggplot boiler-plate code with dynamically generated inputs
