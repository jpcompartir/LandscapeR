# Tibble of examples for LandscapeR functions & tests

Tibble of examples for LandscapeR functions & tests

## Usage

``` r
data("ls_example")
```

## Format

A tibble with 10 rows and 5 columns

- document:

  Post ID

- text:

  Text variable for data table

- permalink:

  Link to original post

- clean_text:

  cleaner version of text variable for plots

- date:

  Date variable in ymd_hms format

- setniment:

  Sentiment variable

- V1:

  x co-ordinates

- V2:

  y co-ordinates
